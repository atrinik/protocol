# Atrinik protocol

This repository is the fresh MIT-licensed source of truth for Atrinik Game Protocol 1: Protobuf schemas, Buf compatibility policy, specifications, fixtures, and generated Go/Rust contracts.

The classic numeric C/Python command registry is maintained in the [`protocol/` module of atrinik/classic](https://github.com/atrinik/classic/tree/main/protocol). Game Protocol 1 is a new contract, not a source port or compatibility extension.

The implementation roadmap is tracked by [atrinik/atrinik#168](https://github.com/atrinik/atrinik/issues/168).
