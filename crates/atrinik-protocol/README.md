# Atrinik Protocol

`atrinik-protocol` contains the generated Rust types and bounded validation
helpers for Atrinik Game Protocol 1 and its adjacent static metaserver
directory contract.

The normative schemas, specifications, fixtures, generators, release
checksums, provenance, and compatibility baseline live in the
[`atrinik/protocol`](https://github.com/atrinik/protocol) repository. Consumers
must use a released crate and must not treat the generated Protobuf types alone
as the complete wire contract.
